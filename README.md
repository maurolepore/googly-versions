# googly-versions

Version history like in Google Docs. Don't worry about Git. Claude Code will.

## Install

In Claude Code, run:

```
/plugin marketplace add maurolepore/googly-versions
```

```
/plugin install googly-versions@googly-versions-marketplace
```

## Usage

Talk to Claude naturally:

- **"show my versions"** — see your version history
- **"name this version X"** — give the current version a name
- **"rename version X to Y"** — rename an existing version
- **"go back to X"** / **"restore version X"** — restore files from a version
- **"undo"** — go back one version
- **"make a copy of version X"** — export a version to a sibling directory

## Autosave

Versions automatically saves your work every time Claude stops. To toggle:

- **"autosave off"** — pause auto-saving
- **"autosave on"** — resume auto-saving

Your version history is preserved even when autosave is off.
